# 514 clickhouse

Use `514 clickhouse` to interact with your project's ClickHouse databases on 514 Hosting.

## Usage

```bash
514 clickhouse [OPTIONS] <COMMAND>
```

## Subcommands

### query

Execute a SQL query against a branch's ClickHouse database.

```bash
514 clickhouse query [OPTIONS] [QUERY]
```

### seed

Copy rows from one branch's ClickHouse table into another.

```bash
514 clickhouse seed [OPTIONS] <TABLE>
```

See the full command reference: [`514 clickhouse seed`](/hosting/cli/clickhouse/seed).

## Examples

```bash
514 clickhouse query "SELECT count() FROM events"
514 clickhouse seed events --from main --limit 1000
```
