<TabsContent value="claude-code">

**Recommended: Stdio proxy** (always starts, even before `moose dev` is running)

```bash copy
claude mcp add moose-dev -- moose mcp
```

The `moose mcp` command runs a lightweight stdio proxy that advertises the same tools as the dev server. When `moose dev` isn't running, tool calls return an error prompting the agent to start it automatically. This means you can configure the MCP server once and it will always be available.

To customize the host or port the proxy connects to:

```bash copy
claude mcp add moose-dev -- moose mcp --host 127.0.0.1 --port 4001
```

**Alternative: Direct HTTP connection**

If you prefer a direct connection (requires `moose dev` to be running first):

```bash copy
claude mcp add --transport http moose-dev http://localhost:4000/mcp
```

<TabsContent value="windsurf">

**Location**: `~/.codeium/windsurf/mcp_config.json`

Windsurf supports native Streamable HTTP transport:

```json filename="mcp_config.json" copy
{
  "mcpServers": {
    "moose-dev": {
      "serverUrl": "http://localhost:4000/mcp"
    }
  }
}
```

<TabsContent value="vs-code">

**Prerequisites**:
- VS Code 1.102+ (built-in MCP support)
- Or install the [Cline extension](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev)

**Option 1: Native HTTP Support (VS Code 1.102+)**

Add to your project's `.vscode/mcp.json` or User Settings:

```json filename=".vscode/mcp.json" copy
{
  "servers": {
    "moose-dev": {
      "type": "http",
      "url": "http://localhost:4000/mcp"
    }
  }
}
```

Confirm the server is running and integrated with VSCode by running `MCP: List Servers` command from the Command Palette.

For other native options, see the [VSCode docs](https://code.visualstudio.com/docs/copilot/customization/mcp-servers#_add-an-mcp-server).

**Option 2: Cline Extension**

Configure in Cline's MCP settings:

```json copy
{
  "moose-dev": {
    "transport": "sse",
    "url": "http://localhost:4000/mcp"
  }
}
```

<TabsContent value="cursor">

**Location**: `.cursor/mcp.json` (project-level) or `~/.cursor/settings/mcp.json` (global)

<Callout type="info">
Cursor currently uses stdio transport. Use `mcp-remote` to bridge to HTTP servers:
</Callout>

```json filename=".cursor/mcp.json" copy
{
  "mcpServers": {
    "moose-dev": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "http://localhost:4000/mcp"
      ]
    }
  }
}
```

</TabsContent>
<TabsContent value="claude-desktop">

**Location**: `~/Library/Application Support/Claude/claude_desktop_config.json`

Access via: Claude > Settings > Developer > Edit Config

```json filename="claude_desktop_config.json" copy
{
  "servers": {
    "moose-dev": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "http://localhost:4000/mcp"
      ]
    }
  }
}
```

<Callout type="info">
The `-y` flag automatically installs `mcp-remote` if not already installed.
</Callout>
