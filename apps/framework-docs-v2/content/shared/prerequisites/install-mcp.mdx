<TabsContent value="claude-code">

**Option 1: Always-On stdio proxy (recommended)**

Run `moose mcp` as a stdio MCP server. It starts immediately without requiring `moose dev` to be running first, and automatically proxies tool calls to the dev server when it is available.

```bash copy
claude mcp add moose-dev -- moose mcp
```

Manual configuration at `~/.claude/config.json`:

```json filename="config.json" copy
{
  "mcpServers": {
    "moose-dev": {
      "command": "moose",
      "args": ["mcp"]
    }
  }
}
```

**Option 2: Direct HTTP connection**

Connect directly to the HTTP MCP endpoint exposed by `moose dev`. Requires the dev server to be running before adding the configuration.

```bash copy
claude mcp add --transport http moose-dev http://localhost:4000/mcp
```

Manual configuration:

```json filename="config.json" copy
{
  "mcpServers": {
    "moose-dev": {
      "transport": "http",
      "url": "http://localhost:4000/mcp"
    }
  }
}
```

<Callout type="info">
With Option 2, make sure `moose dev` is running before adding the server. The CLI will verify the connection.
</Callout>

<TabsContent value="windsurf">

**Location**: `~/.codeium/windsurf/mcp_config.json`

Windsurf supports native Streamable HTTP transport:

```json filename="mcp_config.json" copy
{
  "mcpServers": {
    "moose-dev": {
      "serverUrl": "http://localhost:4000/mcp"
    }
  }
}
```

<TabsContent value="vs-code">

**Prerequisites**:
- VS Code 1.102+ (built-in MCP support)
- Or install the [Cline extension](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev)

**Option 1: Native HTTP Support (VS Code 1.102+)**

Add to your project's `.vscode/mcp.json` or User Settings:

```json filename=".vscode/mcp.json" copy
{
  "servers": {
    "moose-dev": {
      "type": "http",
      "url": "http://localhost:4000/mcp"
    }
  }
}
```

Confirm the server is running and integrated with VSCode by running `MCP: List Servers` command from the Command Palette.

For other native options, see the [VSCode docs](https://code.visualstudio.com/docs/copilot/customization/mcp-servers#_add-an-mcp-server).

**Option 2: Cline Extension**

Configure in Cline's MCP settings:

```json copy
{
  "moose-dev": {
    "transport": "sse",
    "url": "http://localhost:4000/mcp"
  }
}
```

**Location**: `.cursor/mcp.json` (project-level) or `~/.cursor/settings/mcp.json` (global)

Cursor uses stdio transport. Use `moose mcp` directly — no bridge required:

```json filename=".cursor/mcp.json" copy

      "args": ["mcp"]
    }
  }
}
```
