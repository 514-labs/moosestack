# Concepts

The foundational ideas that MooseStack is built on. Start here if you want to understand how Moose runs, how it models your data, and how it integrates with your editor and AI agents.

## Where to start

- [Moose Runtime](/moosestack/runtime) — how MooseStack runs locally and in production.
- [Data Modeling](/moosestack/data-modeling) — how tables, streams, views, and other primitives are defined in code.
- [MooseDev MCP](/moosestack/moosedev-mcp) — the MCP server that lets coding agents interact with your Moose project.
- [Language Server](/moosestack/language-server) — editor integration for TypeScript projects.
