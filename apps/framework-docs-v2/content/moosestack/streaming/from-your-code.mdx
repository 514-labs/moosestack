# Stream.send()

Use `Stream.send()` to publish one or more records to an existing `Stream` when the producer can import your Moose SDK models and `Stream` definition directly. If the producer should only send JSON over HTTP, use an [Ingest API](/moosestack/apis/ingest-api) instead.

This page covers in-process producers. To define the stream itself, start with [Stream](/moosestack/streaming/create-stream).

## When to use

<table>
  <thead>
    <tr>
      <th>Use</th>
      <th>Typical scenarios</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>Stream.send()</code></td>
      <td>An existing app in your monorepo or <a href="/moosestack/workflows">Moose workflows</a>, where you can import the stream definition and other Moose objects directly.</td>
    </tr>
    <tr>
      <td><a href="/moosestack/apis/ingest-api">Ingest API</a></td>
      <td>Services that push events into your system when you do not control that codebase or cannot use Moose objects or clients there directly.</td>
    </tr>
  </tbody>
</table>

`Stream.send()` takes one argument. Pass a single record to publish one message, or pass an array or list to publish multiple messages. There are no per-call options on `send()`.

## Send one record

<LanguageTabs>
  <LanguageTabContent value="typescript">
```ts filename="app/publish.ts" copy
import { userEvents } from "./stream";

await userEvents.send({
  id: "evt_1",
  userId: "user_123",
  timestamp: new Date(),
  eventType: "click",
});
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
```py filename="app/publish.py" copy
from datetime import datetime, timezone

from app.stream import UserEvent, user_events

user_events.send(
    UserEvent(
        id="evt_1",
        user_id="user_123",
        timestamp=datetime.now(timezone.utc),
        event_type="click",
    )
)
```
  </LanguageTabContent>
</LanguageTabs>

## Send many records

Pass an array or list when you want to publish multiple records in one call. Moose publishes one stream record per element, not one array payload.

<LanguageTabs>
  <LanguageTabContent value="typescript">
```ts filename="app/publish.ts" copy
import { userEvents } from "./stream";

await userEvents.send([
  { id: "evt_2", userId: "user_456", timestamp: new Date(), eventType: "view" },
  { id: "evt_3", userId: "user_789", timestamp: new Date(), eventType: "signup" },
]);
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
```py filename="app/publish.py" copy
from datetime import datetime, timezone

from app.stream import UserEvent, user_events

user_events.send([
    UserEvent(
        id="evt_2",
        user_id="user_456",
        timestamp=datetime.now(timezone.utc),
        event_type="view",
    ),
    UserEvent(
        id="evt_3",
        user_id="user_789",
        timestamp=datetime.now(timezone.utc),
        event_type="signup",
    ),
])
```
<Callout type="warning">
Values passed to `send()` must be instances of the stream model type. Passing a `dict` or other non-model value raises `TypeError`.
</Callout>

  </LanguageTabContent>
</LanguageTabs>

## Send nothing

Top-level empty inputs are valid and send nothing:

<LanguageTabs>
  <LanguageTabContent value="typescript">
```ts filename="app/publish.ts" copy
await userEvents.send(undefined);
await userEvents.send(null);
await userEvents.send([]);
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
```py filename="app/publish.py" copy
user_events.send(None)
user_events.send([])
```
  </LanguageTabContent>
</LanguageTabs>

## Behavior

`Stream.send()` publishes to the stream topic. If the stream also has a destination table, records become queryable only after Moose syncs them into ClickHouse.

If the stream is configured for Schema Registry JSON, `send()` publishes using the Confluent wire format automatically. See [Schema Registry](/moosestack/streaming/schema-registry).
