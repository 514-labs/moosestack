# Send records to a Stream

Use `Stream.send()` to publish records into a `Stream` from code running inside your Moose project.

## When to use `Stream.send()`

Use `Stream.send()` when code running inside your Moose project needs to publish directly to a stream topic.

- Use `Stream.send()` for in-process producers such as app code, jobs, or other Moose runtime code.
- Use an [Ingest API](/moosestack/apis/ingest-api) when an external system should publish over HTTP instead of importing the Moose SDK.

## Basic usage

`Stream.send()` accepts either a single record or an array of records:

<LanguageTabs>
  <LanguageTabContent value="typescript">
```ts filename="app/publish.ts" copy
import { Stream } from "@514labs/moose-lib";

interface UserEvent {
  id: string;
  userId: string;
  timestamp: Date;
  eventType: string;
}

const events = new Stream<UserEvent>("events");

// Send a single record
await events.send({
  id: "evt_1",
  userId: "user_123",
  timestamp: new Date(),
  eventType: "click",
});

// Send array of records
await events.send([
  { id: "evt_2", userId: "user_456", timestamp: new Date(), eventType: "view" },
  { id: "evt_3", userId: "user_789", timestamp: new Date(), eventType: "signup" },
]);
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
```py filename="app/publish.py" copy
from datetime import datetime

from moose_lib import Stream
from pydantic import BaseModel

class UserEvent(BaseModel):
    id: str
    user_id: str
    timestamp: datetime
    event_type: str

events = Stream[UserEvent]("events")

events.send(UserEvent(
    id="evt_1",
    user_id="user_123",
    timestamp=datetime.now(),
    event_type="click",
))

events.send([
    UserEvent(id="evt_2", user_id="user_456", timestamp=datetime.now(), event_type="view"),
    UserEvent(id="evt_3", user_id="user_789", timestamp=datetime.now(), event_type="signup"),
])
```
  </LanguageTabContent>
</LanguageTabs>

- Passing an array publishes multiple stream records, not one array payload.
- Passing `null`, `undefined`, or an empty array sends nothing.
- `Stream.send()` publishes to the stream topic. If the stream also has a destination table, records become queryable only after Moose syncs them into ClickHouse.

<Callout type="info" title="Schema Registry JSON works automatically">
If your stream uses `schemaConfig.kind = "JSON"`, Moose publishes records with the Confluent Schema Registry envelope automatically. See [Schema Registry](/moosestack/streaming/schema-registry).
</Callout>

## Requirements and errors

- If the stream uses `schemaConfig.kind = "JSON"`, configure `schema_registry_url` before calling `send()`.
- Only JSON Schema is supported for Schema Registry streams today.
- In Python, values passed to `send()` must be instances of the stream model type.
- In Python, Schema Registry JSON support requires `confluent-kafka[json,schemaregistry]`.

## Publish from external systems

Use an [Ingest API](/moosestack/apis/ingest-api) instead of `Stream.send()` when the producer runs outside your Moose project and should `POST` JSON into a stream over HTTP.
