# Stream

Use `Stream<T>` to define a typed Kafka or Redpanda-backed stream in your Moose project. A `Stream` names the topic, defines the record shape, and becomes the object you publish to, consume from, transform, or sync into ClickHouse.

<Callout type="info" title="Enable Moose Streams before defining streams">
Turn on `features.streaming_engine` in `moose.config.toml` before creating `Stream` resources.
</Callout>

```toml filename="moose.config.toml"
[features]
streaming_engine = true
```

## Basic usage

<LanguageTabs>
  <LanguageTabContent value="typescript">
```ts filename="app/stream.ts" copy
import { Stream } from "@514labs/moose-lib";

interface Record {
  id: string;
  name: string;
  timestamp: Date;
}

export const stream = new Stream<Record>("stream");
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
```py filename="app/stream.py" copy
from datetime import datetime

from moose_lib import Stream
from pydantic import BaseModel

class Record(BaseModel):
    id: str
    name: str
    timestamp: datetime

stream = Stream[Record]("stream")
```
  </LanguageTabContent>
</LanguageTabs>

## Add a destination table

Attach a `destination` OLAP table when records from the stream should be batched and written into ClickHouse automatically.

<LanguageTabs>
  <LanguageTabContent value="typescript">
```ts filename="app/stream.ts" copy
import { Stream } from "@514labs/moose-lib";
import { table } from "./table";

interface Record {
  id: string;
  name: string;
  timestamp: Date;
}

export const stream = new Stream<Record>("stream", {
  destination: table,
  version: "0.0",
});
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
```py filename="app/stream.py" copy
from datetime import datetime

from moose_lib import Stream, StreamConfig
from app.table import table
from pydantic import BaseModel

class Record(BaseModel):
    id: str
    name: str
    timestamp: datetime

stream = Stream[Record]("stream", config=StreamConfig(
    destination=table,
    version="0.0",
))
```
  </LanguageTabContent>
</LanguageTabs>

For batching and delivery behavior after records enter ClickHouse sync, see [Sync to table](/moosestack/streaming/sync-to-table).

## Example configuration

<LanguageTabs>
  <LanguageTabContent value="typescript">
```ts filename="app/stream.ts" copy
import { DeadLetterQueue, LifeCycle, Stream } from "@514labs/moose-lib";

interface Record {
  id: string;
  timestamp: Date;
}

const streamDLQ = new DeadLetterQueue<Record>("high_throughput_dlq");

export const stream = new Stream<Record>("high_throughput", {
  version: "0.1",
  parallelism: 4,
  retentionPeriod: 86400,
  defaultDeadLetterQueue: streamDLQ,
  lifeCycle: LifeCycle.FULLY_MANAGED,
});
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
```py filename="app/stream.py" copy
from datetime import datetime

from moose_lib import DeadLetterQueue, LifeCycle, Stream, StreamConfig
from pydantic import BaseModel

class Record(BaseModel):
    id: str
    timestamp: datetime

stream_dlq = DeadLetterQueue[Record]("high_throughput_dlq")

stream = Stream[Record]("high_throughput", config=StreamConfig(
    version="0.1",
    parallelism=4,
    retention_period=86400,
    default_dead_letter_queue=stream_dlq,
    life_cycle=LifeCycle.FULLY_MANAGED,
))
```
