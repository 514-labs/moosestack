# Quickstart (moved)

The maintained MooseStack day-one tutorial lives at [5-Minute Quickstart](/moosestack/getting-started/quickstart).

Use that page for the tested happy path:

- Install Moose
- Create a project
- Run `moose dev`
- Trigger the sample workflow
- Verify the generated API output

If you are starting from an existing ClickHouse deployment instead of a new app, use [Use Moose with Your Existing ClickHouse](/moosestack/getting-started/from-clickhouse).

This route stays in place so older links still resolve, but the tutorial above is the version we keep up to date.
