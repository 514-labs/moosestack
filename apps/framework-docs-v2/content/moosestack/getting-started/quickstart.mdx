## Step 1: Install Moose

### Run the installation script

```bash filename="Terminal" copy
bash -i <(curl -fsSL https://fiveonefour.com/install.sh) moose
```

You should see: `Moose vX.X.X installed successfully!`

If you see an error instead, check [Troubleshooting](#need-help) below.

### Reload your shell configuration

**This step is required.** Your current terminal doesn't know about the `moose` command yet.

<Tabs defaultValue="zsh">
<TabsList>
<TabsTrigger value="zsh">Zsh (most macOS)</TabsTrigger>
<TabsTrigger value="bash">Bash (most Linux)</TabsTrigger>
</TabsList>
<TabsContent value="zsh">

```bash filename="Terminal" copy
source ~/.zshrc
```

</TabsContent>
<TabsContent value="bash">

If `echo $SHELL` showed `/bin/bash` or `/usr/bin/bash`:

```bash filename="Terminal" copy
source ~/.bashrc
```

</TabsContent>
</Tabs>

### Verify moose command works

```bash filename="Terminal" copy
moose --version
```

You should see:
```txt
moose X.X.X
```

<Callout type="warning" title="If you see 'command not found'" compact={true}>

**Try these steps in order:**

1. Re-run the correct `source` command for your shell
2. Close this terminal completely and open a new terminal window
3. Run `moose --version` again
4. If still failing, see [Troubleshooting](#need-help)

</Callout>

<Callout type="success" title="Checkpoint" icon="Check" compact={true}>
You should see the moose version number. Do not proceed to Step 2 until `moose --version` works.
</Callout>

## Step 3: Start the harness

```bash filename="Terminal" copy
moose dev
```

For AI assistants or when you need a second terminal:
```bash
nohup moose dev &
```

<Callout type="info" title="This may take a minute the first time." compact={true}>
Moose is downloading Docker images for ClickHouse, Redpanda, and Temporal, starting containers, and initializing the MCP server.
</Callout>

Wait for the `Started Webserver` message before proceeding:

```txt
       Created docker compose file
⡗ Starting local infrastructure
  Successfully started containers
     Validated clickhousedb-1 docker container
     Validated redpanda-1 docker container
  Successfully validated red panda cluster
     Validated temporal docker container
  Successfully ran local infrastructure
      Node Id: my-app::b15efaca-0c23-42b2-9b0c-642105f9c437
      Starting development mode
      Watching "/path/to/my-app/app"
       Started Webserver.  👈 WAIT FOR THIS
```

<Callout type="success" title="Checkpoint" icon="Check" compact={true}>
Keep this terminal running. Your MCP server is live at `localhost:4000/mcp`. Open a new terminal for the next step.
</Callout>

## Need Help?

<ToggleBlock openText="Docker Not Running" closeText="Docker Not Running">
Make sure Docker is running:
```bash filename="Terminal" copy
# macOS
open -a Docker

# Linux
sudo systemctl start docker

# Verify Docker is running
docker ps
```

If Docker is running but you're still having issues, try clearing your Docker cache:
```bash filename="Terminal" copy
docker system prune -a
```
</ToggleBlock>

<ToggleBlock openText="Outdated Language Version" closeText="Outdated Language Version">
<LanguageTabs>
  <LanguageTabContent value="typescript">
Make sure you're using Node.js 20 or later:
```bash filename="Terminal" copy
# Check version
node -v

# Install Node 20+ with nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 20
nvm use 20
```
  </LanguageTabContent>
  <LanguageTabContent value="python">
Make sure you're using Python 3.12 or later:
```bash filename="Terminal" copy
# Check version
python3 --version

# Install Python 3.12+ with pyenv
curl https://pyenv.run | bash
pyenv install 3.12
pyenv local 3.12
```
  </LanguageTabContent>
</LanguageTabs>
</ToggleBlock>

<ToggleBlock openText="Port Conflicts" closeText="Port Conflicts">
Use one of the following options to resolve a "Port 4000 already in use" error (or any other port conflict):

**Option 1: Kill the process**
```bash filename="Terminal" copy
# Find what's using port 4000
lsof -i :4000

# Kill the process (replace PID)
kill -9 <PID>
```

**Option 2: Use a different port**
Set a different port in `moose.config.toml` in your project root:
```toml filename="moose.config.toml" copy
[http_server_config]
port = 4001
```

Restart `moose dev` after saving.

<Callout type="info" title="Customizing Ports for Local Infrastructure" compact={true}>
You can also customize ClickHouse, Redpanda, and Temporal ports. See the [Configuration Reference](/moosestack/configuration#mooseconfigtoml-reference).
</Callout>
</ToggleBlock>
