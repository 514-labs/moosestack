# Read data

Run queries against an [`OlapTable`](/moosestack/olap/model-table) or [`MaterializedView`](/moosestack/olap/model-materialized-view) from application code. Pick the tool that matches your language and query style.

## Where to start

- [Query client](/moosestack/olap/moose-client) — set up the TypeScript or Python client and execute queries.
- [SQL tag](/moosestack/olap/sql-tag) — TypeScript SQL helpers for building type-safe queries with `sql.statement`, `sql.fragment`, `sql.join`, and `sql.raw`.
- [Python query builder](/moosestack/olap/query-builder) — build typed Python queries with `Query().from_().select().where()`.
- [Query Layer](/moosestack/reference/query-layer) — semantic query models for reusable typed queries.

## Related capabilities

- [Model table](/moosestack/olap/model-table) for defining the tables you query
- [Materialized view](/moosestack/olap/model-materialized-view) for write-time projections backed by target tables
- [Semantic layer](/moosestack/apis/semantic-layer) for packaging OLAP queries behind reusable API models
- [Insert data](/moosestack/olap/insert-data) for writing data into OLAP tables
