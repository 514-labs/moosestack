# Codecs

Reference for the `ClickHouseCodec` annotation, which sets per-column compression on an [`OlapTable`](/moosestack/olap/model-table). Codecs let you tune storage size and decompression cost individually for each column — replacing the default codec chain with one matched to the column's value distribution.

## What this page covers

- `ClickHouseCodec<"...">` (TS) / `ClickHouseCodec("...")` (Py) — per-column compression annotation
- Codec chains (e.g. `"Delta, LZ4"`, `"Gorilla, ZSTD"`) — applied left-to-right
- Specialized codecs: `Delta`, `DoubleDelta`, `Gorilla`, `T64`, `FPC`
- General-purpose codecs: `LZ4`, `ZSTD(level)`, `NONE`
- Combining codecs with other column annotations (`ClickHouseMaterialized`, `ClickHouseDefault`, `ClickHouseTTL`)
- When per-column codecs are worth the complexity vs the default chain
