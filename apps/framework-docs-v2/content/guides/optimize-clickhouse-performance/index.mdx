# Optimizing ClickHouse Performance with AI

<Callout type="info" title="TL;DR">
  * This guide is for MooseStack apps that already have a slow ClickHouse query
  path in production. * The optimization workflow profiles that query, proposes
  schema changes, benchmarks the result on preview, and opens a PR. * Your job
  is to review the evidence, the migration plan, and the exact test artifacts
  before merge.
</Callout>

You need the `514` CLI installed, signed in, and your repo linked to your Fiveonefour project (see the **Setup** section in the [tutorial](/guides/optimize-clickhouse-performance/tutorial) and [Hosting](/hosting)). The tutorial then covers **Optimization workflow** and **PR review** in separate sections.
