# Production-Ready Analytics Agent

Authors: Nakul Mishra (Senior Solutions Architect, AWS) & Chris Crane (Cofounder/Product, Fiveonefour)

Build an AI agent that can query your data, extract insights, and present findings — safely, reliably, and fast. This guide uses the [`typescript-agent` template](https://github.com/514-labs/moosestack/tree/main/templates/typescript-agent), a complete reference implementation with the Analytics Agent Harness already wired: JWT auth, multi-tenant row-level security, multi-agent orchestration, observability, a semantic layer, and guardrails.
