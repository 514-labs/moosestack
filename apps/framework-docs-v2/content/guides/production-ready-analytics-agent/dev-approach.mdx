# Dev Approach

This guide assumes you'll use a coding agent to accelerate your build. Additionally, this guide proposes using a Coding Agent Harness: that will set your coding agent up for success to safely, quickly, effectively build out your production-ready Analytics Agent and Analytics Agent Harness.

## Why use a Coding Agent Harness

If you're building a prototype, a coding agent can probably get you all the way there on its own. But if you're building production-ready analytics agents on real-time analytical infrastructure, coding agents tend to run into a predictable set of problems:

<BulletPointsCard
  bulletStyle="x"
  bullets={[
    {
      title: "Missing best practices for data engineering and OLAP",
      description: "Agents don't have the right specialization for real-time analytical infrastructure. Wrong key design, missing LowCardinality, ORDER BY that kills query performance at scale.",
    },
    {
      title: "No tight, safe, local feedback loop",
      description: "Errors surface at deploy time, not write time. Without the right context immediately available, agents can't catch and fix mistakes as they go.",
    },
    {
      title: "No infrastructure interfaces built for how coding agents work",
      description: "CLIs, MCPs, APIs, and code-based interfaces are how coding agents operate effectively. Without them, agents can't interact with or validate against the running infrastructure.",
    },
  ]}
/>

The result: you don't get a production-ready application quickly or safely. The Coding Agent Harness fixes this by giving the coding agent everything it needs to be successful.

## What is the Coding Agent Harness

The Coding Agent Harness is an integrated environment that exposes all the infrastructure, interfaces, tools, skills, code, and context a coding agent needs to rapidly and safely build production-ready analytics infrastructure.
